# Security Policy

## Reporting a vulnerability

If you discover a security issue in this project, please report it privately
rather than opening a public issue.

- **Email:** ogs1905.com@gmail.com
- Include steps to reproduce, affected endpoint or component, and impact.
- You'll get an acknowledgement as soon as possible, and I'll work on a fix
  before any public disclosure.

Please do not run automated scanners or intrusive tests against any live
deployment without permission.

## Scope

This is a personal portfolio project. Security-relevant areas include the
authentication flow (`/api/auth`), the admin API (`/api/*` write endpoints),
and input handling on the contact form.
